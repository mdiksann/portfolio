# Muhammad Iksan — Portfolio

My personal portfolio as a Backend Developer / Cloud Engineer, showcasing my projects, professional experience, and the technologies I work with.

I also write about system architecture and cloud infrastructure on my blog, sharing what I learn while building each project.

## What's Inside

- Selected projects with implementation overviews and their tech stacks.
- Professional experience and areas of expertise.
- Articles on backend development, system architecture, and cloud infrastructure.
- Contact details for collaboration and freelance work.

The website is available in Indonesian and English, with a responsive layout for desktop and mobile.

## Built With

Built with Next.js, React, TypeScript, and Tailwind CSS. Payload CMS manages the content, while Framer Motion handles interface animations.

This repository contains the source code for my personal portfolio website.
